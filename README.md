# Nexo — versão HTML, CSS e JavaScript

Esta pasta contém a versão sem React, TypeScript, Vite ou Tailwind do protótipo exportado do Figma.

## Arquivos

- `index.html`: estrutura inicial e referências dos arquivos.
- `style.css`: estilos e responsividade.
- `script.js`: navegação, renderização das telas, motor de decisão de energia e interações.
- `favicon.svg`: ícone da aba do navegador.

## Como abrir no VS Code

1. Extraia o ZIP para uma pasta.
2. Abra a pasta pelo VS Code (`Arquivo > Abrir Pasta`).
3. Abra `index.html` no navegador. Para desenvolvimento, use a extensão **Live Server** e clique em **Go Live**.

Não é necessário executar `npm install` nem configurar um processo de build.

## Observação

É um protótipo demonstrativo: login, integrações, telemetria e acionamento físico não estão conectados a um back-end ou a equipamentos reais. As decisões e alterações ficam no estado da página durante a sessão.
